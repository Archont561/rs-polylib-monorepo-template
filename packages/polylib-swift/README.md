# `polylib-swift` (Swift Package)

Idiomatic Swift library wrapping `crates/polylib-ffi` via `UniFFI` and SwiftPM.

## Layout

- `Package.swift`: SwiftPM manifest wiring `PolylibFFIInternal` (C header + modulemap), `PolylibFFI` (generated Swift FFI), `Polylib` (idiomatic Swift facade), and `PolylibTests`.
- `Sources/Polylib/Polylib.swift`: Idiomatic Swift facade (`Polylib`, `ScoreSummary`, `PolylibError`).
- `Sources/PolylibFFI/`, `Sources/PolylibFFIInternal/include/`, and `.native/`: Generated by `pixi run -e rust tools run ffi build --target swift` (gitignored).
- `Tests/PolylibTests/`: XCTest unit tests and shared `conformance/*.feature` conformance runner.

## Local Commands

```sh
pixi run -e rust tools run ffi build --target swift
pixi run -e rust tools run ffi test --target swift
pixi run -e rust tools run ffi compat --target swift
```
